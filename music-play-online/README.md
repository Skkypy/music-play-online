# Music Play Online

一个 Chrome 浏览器扩展插件，聚合多种在线音乐源的歌曲到统一播放列表，支持顺序、随机、单曲循环播放。

## 功能特性

- **多源支持**：支持歌曲宝等在线音乐平台的歌曲
- **播放列表管理**：可添加、移除、清空歌曲
- **多种播放模式**：顺序播放、随机播放、单曲循环
- **浮动播放条**：页面右下角显示迷你播放器
- **跨窗口通信**：自动从音乐页面获取音频链接

## 安装方法

1. 下载/克隆本项目
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的 `src` 文件夹

## 使用方法

### 添加歌曲

1. 打开歌曲宝的合集页面（如 `https://www.gequbao.com/topic/wangfei-zw1lzb`）
2. 每首歌曲旁边会显示「＋」按钮
3. 点击「＋」将歌曲添加到播放列表
4. 或在歌曲详情页面点击「＋ 添加到播放列表」

### 播放控制

- 点击浮动播放条的播放/暂停按钮
- 使用上一首/下一首切换歌曲
- 点击播放列表按钮查看当前播放列表
- 选择播放模式：顺序、随机或单曲循环

## 支持的页面

- 歌曲宝合集页面：`/topic/`
- 歌曲宝单曲页面：`/music/`
